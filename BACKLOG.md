## Donut view for the section breakdown

A toggle that shows each section's share of the runtime as a donut chart, with the total runtime in the center.

Parked because the timeline bar already shows the same shares and, unlike a donut, keeps the sections in script order. Close slices (e.g. 16.5% vs 18.8%) are also hard to tell apart in a donut. It's mainly a presentation view, so it's worth revisiting if people want it for slides or screenshots. It can be built as inline SVG, with no chart library.
